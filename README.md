# Click Way

Sistema de navegação interna para rodoviárias — MVP acadêmico, mobile-first, sem backend.

## Como rodar

```bash
npm install
npm run dev
```

## Antes de pedir para uma IA continuar o projeto

Este projeto segue um protocolo de continuidade entre sessões de IA. Antes de
gerar qualquer código novo, a IA deve ler, nesta ordem:

1. `click-way-spec.md` (especificação completa, começando pela seção 0)
2. `PROGRESS.md` (o que já foi feito e quais decisões foram tomadas)
3. O código já existente em `src/`

Veja a seção 0 do `click-way-spec.md` para o protocolo completo.
